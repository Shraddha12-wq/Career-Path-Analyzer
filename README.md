
# Smart Career Path Analyzer

A Java-based web application that helps students identify suitable career paths based on their skills, interests, aptitude, and assessment performance.

## Project Overview

Smart Career Path Analyzer is a web-based career guidance system developed using Java, JSP, Servlets, JDBC, and MySQL.

The application allows users to register, log in, complete career assessments, view results, and explore suitable career paths.

Administrators can manage users, questions, courses, feedback, and reports.

## Features

- User Registration and Login
- Career Assessment
- Basic, Intermediate, Advanced and Expert Questions
- Aptitude Assessment
- Career Recommendations
- Personalized Career Roadmap
- User Assessment History
- Course Management
- Admin Dashboard
- Feedback and Contact Management
- PDF Report Generation

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Shraddha12-wq/Career-Path-Analyzer.git
```

2. Import the project into Eclipse as an Existing Maven Project.

3. Configure MySQL database.

4. Update database connection details in DBConnection.java.

5. Configure Apache Tomcat Server.

6. Build the Maven project.

7. Run the application on the Tomcat server.
